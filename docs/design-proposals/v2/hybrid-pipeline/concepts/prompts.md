# Hybrid Pipeline: concept prompts

Model: Azure deployment gpt-image-2.5-flare, images/generations, 1536x1024, quality high. Script: `gen.py <name>` (reads `prompts.json`, holds `/tmp/viaform-azure.lock` per call, retries 429 and 5xx with backoff).
Desk screens send `common` + the screen prompt; the iPad screen sends `common_ipad` + its prompt. Each screen was accepted on its first try (2026-11-04).
